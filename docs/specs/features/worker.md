# Worker — Implementation Spec

## Goal
The Workers entrypoint, `wrangler.toml` config, SPA fallback for unknown paths, and the generated runtime types that make `Env` / `ExportedHandler` resolve in TypeScript.

## Requirements covered
- §FR-1.4.1 — Deploys to Cloudflare Workers + Static Assets (not Pages).
- §FR-1.4.2 — `src/worker.ts` is a pass-through to `env.ASSETS.fetch(req)`.
- §FR-1.4.3 — `not_found_handling = "single-page-application"` (unknown paths serve `index.html`).
- §FR-1.4.4 — Served from `moster.dev` with automatic HTTPS.
- §FR-1.4.5 — Single `wrangler.toml` covers static + future dynamic.
- §FR-1.6.1 — Worker runtime types generated by `bunx wrangler types`.
- §FR-1.6.2 — `tsconfig.json` `types` includes `"./worker-configuration.d.ts"`.
- §FR-1.6.3 — Generated file is gitignored; regen is part of `bun run check`.

## File layout
- `src/worker.ts` — pass-through fetch handler. See [architecture §4.2](../architecture.md#42-srcworkerts-pass-through-stub) for the canonical code.
- `wrangler.toml` — see [architecture §4.1](../architecture.md#41-wranglertoml-static-only-day-1) for the canonical config.
- `worker-configuration.d.ts` — generated by `bunx wrangler types`, gitignored.

## Behavior & edge cases
- `worker.ts` is intentionally one expression — `env.ASSETS.fetch(req)`. The point of having it from day 1 is so the deploy shape never has to change when the first dynamic route arrives.
- `wrangler.toml` sets `compatibility_date` to the date of the most recent meaningful edit (currently `"2026-05-17"`).
- The `[[routes]]` block stays commented out until the first `/api/*` handler is added, at which point uncomment and set `pattern = "moster.dev/api/*"`, `zone_name = "moster.dev"`.
- `worker-configuration.d.ts` is **not** committed. Anyone cloning fresh runs `bunx wrangler types` before `tsc`.
- `tsconfig.json` `compilerOptions.types` array must list both `"bun"` and `"./worker-configuration.d.ts"` — order doesn't matter, but both must be present, otherwise `Env` resolves to `any`.
- `bun run check` order: `wrangler types` → `biome check` → `tsc --noEmit`. Regen comes first so the type check sees current bindings.

## Test plan
- **Pre-deploy smoke:** `bun run preview` (wrangler dev) serves the built site without errors.
- **E2E:** request `/some-unknown-path` returns the SPA shell (status 200, body contains `<div id="root">`), not a 404 — satisfies the §6 acceptance line.
- **Type check:** `bunx tsc --noEmit` resolves `Env`, `ExportedHandler<Env>`, and `Fetcher` from the generated file.
